# 🌿 Bahçe Takip Sistemi

Bahçe ve bitki bakımını takip etmek için geliştirdiğim basit bir web uygulaması.

## ✨ Özellikler

* 🌱 Bitki arama ve bitki bilgilerini görüntüleme
* 🪴 Bitkiyi bahçeye ekleme
* 📅 Ekim tarihinin uygunluğunu kontrol etme
* 🌦️ Şehre göre hava durumu bilgisi alma
* 💧 Sulama zamanını takip etme
* 🌿 Gübreleme zamanını takip etme
* 🌾 Bitkiyi hasat etme veya silme
* 🔔 Bakım bildirimleri
* 💾 Bahçe bilgilerinin `localStorage` ile saklanması

## 🛠️ Kullanılan Teknolojiler

* HTML
* CSS
* JavaScript
* JSON
* OpenWeatherMap API
* LocalStorage
